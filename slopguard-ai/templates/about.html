ABOUT THE PROJECT

Quality signals, with
the math in view.

SlopGuard measures patterns that can make writing less useful: repeated wording, generic filler, thin information, and overused keywords.

What scores mean

The slop-pattern score is a weighted, rule-based estimate: 25% inverse information-density proxy, 22% repetition, 18% sentence word overlap, 20% generic phrase patterns, 10% potential keyword stuffing, and 5% other linguistic pattern signals. Content quality is 100 minus the slop-pattern score. The result is an aid to review, not an objective truth.

What scores do not mean

AI authorship cannot be reliably inferred from generic writing patterns alone. This application marks authorship inconclusive and does not label content as AI-written. The offline semantic signal uses word overlap; it is not a sentence embedding model.

Optional integrations

Hugging Face and OpenAI integrations are optional. Hugging Face runs only when a model is configured, and OpenAI review runs only when explicitly selected. API credentials stay on the server in environment variables. When services are unavailable, transparent offline analysis continues.

Webpage analysis

URL fetching is limited to public HTTP/HTTPS pages, validates every redirect, blocks non-public IP ranges, enforces timeouts and a 2 MB response limit, and treats page text as untrusted input.
